# サービス概要
日常で受けた「ありがとう」を記録し、忘れた頃に振り返ることで自己肯定感を高めるアプリです。
誰にどんな場面で感謝されたかを蓄積し、自分の貢献を可視化できます。
落ち込んだ時や自信を失いかけた時に、過去の「ありがとう」が心の支えになります。

## このサービスへの思い・作りたい理由

### きっかけとなったエピソード
私自身、教師という仕事をしている中で誰かの役に立てた時に「ありがとう」と言われることがあります。その瞬間は嬉しいのですが、忙しい毎日の中ですぐに忘れてしまい、またありきたりなものとなっていくことが多々ありました。

そんな私はある時、ふと道端で出会った見ず知らずのお年寄りが落とした物を拾ってあげた時に、ありがとうと言われました。
ふだん頻繁に聞いているはずの言葉だったのに、その瞬間のありがとうには、すごく自己肯定感があがりました。
私自身「ありがとう」という言葉の価値を改めて気づくきっかけとなりました。
その時に、**人は自分が誰かの役に立ったことを忘れやすいけれど、その記録があれば自信につながるのでは**と感じました。

### このサービスを作りたい理由
現代社会では、SNSの「いいね」のような表面的な承認は溢れていますが、**実際に自分が行動したことで誰かが喜んでくれた記録**は意外と残りません。特に、自己肯定感が低くなりがちな社会人にとって、「自分の価値」を客観的に確認できる仕組みが必要だと考えました。

また、感謝されたことをただ記録するだけでなく、**忘れた頃に振り返る体験**を通じて、自分の存在価値を再認識できるサービスにしたいと思いました。過去の「ありがとう」が、落ち込んだ時の心の支えになる。そんな「感謝の貯金」ができるアプリを作りたいと考えています。

## ユーザー層について

### メインターゲット：20代〜40代の社会人（特に自己肯定感を高めたい方）

**このユーザー層を選んだ理由：**
- 仕事や人間関係でストレスを感じやすく、自己肯定感が低下しやすい年齢層
- 「自分は役に立っているのか」「認められているのか」という不安を抱えやすい
- スマートフォンを日常的に使い、記録習慣を持ちやすい
- 自己成長や振り返りに関心があり、アプリを継続的に使う動機を持ちやすい

### サブターゲット：子育て中の親や介護に携わる方

**このユーザー層を選んだ理由：**
- 日々の貢献が見えにくく、感謝されても忘れがち
- 「当たり前」と思われがちな仕事の中で、自分の頑張りを認めてほしいというニーズが強い

## サービスの利用イメージ

### 日常での利用シーン
**記録する場面：**
- 仕事で同僚から「助かったよ、ありがとう」と言われた時、休憩時間にさっと記録
- 家族から「いつもありがとう」と言われた時、寝る前に振り返りながら記録
- 友人から「相談に乗ってくれてありがとう」と言われた時、帰宅後に記録

**振り返る場面：**
- 仕事で失敗して落ち込んだ時、過去の記録を見返して「自分も誰かの役に立っている」と実感
- なんとなく気分が沈んでいる時、ランダム表示機能で過去の「ありがとう」に出会い、元気をもらう
- 週末に1週間分の記録を見返して、「今週も頑張った」と自分を労う

### ユーザーが得られる価値
1. **自己肯定感の向上**：記録が増えるほど、自分の貢献が可視化される
2. **心の支え**：落ち込んだ時に過去の「ありがとう」が励ましてくれる
3. **自分の強みの発見**：長期的に記録することで、どんな場面で感謝されるかが見えてくる
4. **ポジティブな習慣化**：感謝に目を向ける習慣ができ、日常が前向きになる

### 操作イメージ
- **記録は30秒で完了**：「誰に」「何をして」「どんな気持ちだったか」を簡単入力
- **一覧でいつでも振り返り**：時系列で過去の記録を確認
- **ランダム表示で再発見**：過去の記録がランダムに表示され、忘れていた「ありがとう」に再会

## ユーザーの獲得について

### SNSでの情報発信
- **X（Twitter）やInstagram**で、自己肯定感向上や感謝の大切さに関する投稿を継続的に発信
- ハッシュタグ「#ありがとう貯金」「#自己肯定感」「#感謝記録」を活用
- 実際に使ってくれたユーザーの体験談をシェア（許可を得た上で）

## サービスの差別化ポイント・推しポイント

### 既存サービスとの比較

**一般的な日記アプリ・感謝日記アプリとの差別化：**

| 項目 | 既存の日記アプリ | ありがとう貯金 |
|------|-----------------|--------------|
| 記録内容 | その日あった全ての出来事 | 「ありがとう」に特化 |
| 入力の手軽さ | 自由記述で時間がかかる | 項目入力で30秒で完了 |
| 振り返りやすさ | 膨大な記録から探すのが大変 | 「ありがとう」だけなので見返しやすい |
| 心理的効果 | ネガティブな内容も含まれる | ポジティブな記録のみで必ず前向きになれる |

### このアプリの推しポイント

1. **「ありがとう」に特化した設計**
   - 記録する内容を絞ることで、入力の手軽さと振り返りやすさを両立
   - 「感謝された体験」だけを集めるので、見返す時に必ず自己肯定感が上がる

2. **忘れた頃に出会える仕組み**
   - ランダム表示機能により、過去の記録が予期せぬタイミングで現れる
   - 「そんなこともあったな」と再発見することで、より強い感動が得られる

3. **シンプルで続けやすい**
   - 複雑な機能は排除し、「記録」と「振り返り」に集中
   - スマートフォンで30秒以内に入力完了

4. **プライベートな記録として安心**
   - 他人に公開されない、自分だけの「感謝の貯金箱」
   - SNSのような「見せる」記録ではなく、自分のための記録

5. **記録が増えるほど価値が高まる**
   - 長く使うほど、自己肯定感の「貯金」が増えていく
   - 辛い時に過去の記録が多いほど、心の支えとして機能する

## 機能候補

### MVPリリース時に実装する機能（必須機能）

**1. ユーザー認証機能**
- ユーザー登録・ログイン・ログアウト（Devise使用）

**2. 「ありがとう」記録のCRUD機能**
- 記録の新規作成
  - 日付（デフォルト：今日）
  - 誰から感謝されたか（自由記入）
  - どんなシチュエーションか（自由記入）
  - 自分の気持ち・メモ（任意）
- 記録の一覧表示（時系列順、新しい順）
- 記録の詳細表示
- 記録の編集
- 記録の削除

**3. シンプルな検索・フィルタリング機能**
- 日付範囲での絞り込み
- フリーワード検索（Ransack使用）

**4. ランダム表示機能**
- 過去の記録からランダムに1件表示
- 「今日の思い出」として、トップページに表示

### 本リリース後に実装したい機能（追加機能）

**1. 統計・可視化機能**
- 月ごとの記録数をグラフ表示

**2. カテゴリー・タグ機能**
- 「仕事」「家族」「友人」などのカテゴリー分類

**3. リマインダー機能**
- 「今日も記録しましょう」という優しい通知
- 「あの頃○○してくれてありがとう」のような通知
